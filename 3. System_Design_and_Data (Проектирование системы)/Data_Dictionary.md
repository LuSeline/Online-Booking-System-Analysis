# Data Dictionary (Описание сущностей БД)

## 1. Сущность: Persona (Персоны)
**Назначение:** Хранение учетных данных всех пользователей системы.

| Атрибут | Тип данных | Обязательность | Описание |
| :--- | :--- | :---: | :--- |
| **persona_id** | UUID | PK | Уникальный идентификатор персоны |
| **login** | VARCHAR(50) | YES | Логин для доступа в систему |
| **password_hash** | VARCHAR(255) | YES | Хеш пароля (безопасное хранение) |
| **first_name** | VARCHAR(50) | YES | Имя |
| **last_name** | VARCHAR(50) | YES | Фамилия |
| **phone_number** | VARCHAR(15) | YES | Контактный телефон (+7...) |
| **registration_date** | TIMESTAMP | YES | Дата регистрации |

## 2. Сущность: Client (Клиенты)
**Назначение:** Данные посетителей барбершопа.

| Атрибут | Тип данных | Обязательность | Описание |
| :--- | :--- | :---: | :--- |
| **client_id** | UUID | PK | Уникальный ID клиента |
| **persona_id** | UUID | FK (Ref. Persona) | Ссылка на профиль персоны |
| **registration_date** | TIMESTAMP | YES | Дата регистрации клиента |
| **last_visit_date** | TIMESTAMP | NO | Дата последнего визита |

## 3. Сущность: Employee (Сотрудники)
**Назначение:** Данные персонала и мастеров.

| Атрибут | Тип данных | Обязательность | Описание |
| :--- | :--- | :---: | :--- |
| **employee_id** | UUID | PK | ID сотрудника |
| **persona_id** | UUID | FK (Ref. Persona) | Ссылка на профиль персоны |
| **entry_date** | DATE | YES | Дата выхода на работу |
| **is_active** | BOOLEAN | YES | Статус (TRUE - работает, FALSE - уволен) |
| **position** | VARCHAR(50) | YES | Должность |

## 4. Сущность: Service_Slots (Слоты обслуживания)
**Назначение:** Расписание записей (факты записи клиентов).

| Атрибут | Тип данных | Обязательность | Описание |
| :--- | :--- | :---: | :--- |
| **slot_id** | UUID | PK | ID слота |
| **slot_date** | DATE | YES | Дата оказания услуги |
| **start_time** | TIME | YES | Время начала (длительность 60 мин) |
| **employee_id** | UUID | FK (Ref. Employee) | Мастер |
| **client_id** | UUID | FK (Ref. Client) | Клиент (может быть NULL, если слот свободен) |

## 5. Сущность: Discounts (Скидки)
**Назначение:** Система лояльности.

| Атрибут | Тип данных | Обязательность | Описание |
| :--- | :--- | :---: | :--- |
| **discount_id** | UUID | PK | ID скидки |
| **client_id** | UUID | FK | Ссылка на клиента |
| **type_discount** | VARCHAR(20) | YES | Тип (фиксированная / процент) |
| **discount_amount** | DECIMAL(10,2) | YES | Размер скидки |
| **description** | VARCHAR(200) | YES | Описание (День рождения и т.д.) |
