# Online-Booking-System-Analysis
Анализ и проектирование системы онлайн-записи (SaaS)

О проекте
В этом репозитории представлены артефакты системного анализа для разработки системы онлайн-записи сети барбершопов. Это SaaS-платформа, которая заменяет ручной процесс записи, автоматизирует работу администраторов и помогает удерживать клиентов. Работа над проектом продолжается в рамках учебы.

Бизнес-цели и задача

Руководством была поставлена задача внедрить инструмент для:

Роста клиентской базы: возможность записи 24/7 (в том числе для незарегистрированных пользователей).

Снижения нагрузки на персонал: автоматизация рутины (звонки, напоминания, подтверждения).

Улучшения сервиса: сбор обратной связи и контроль качества работы мастеров.

Проделанная работа (Методология)

В ходе работы над проектом я прошла полный цикл системного анализа. В репозиторий выложены ключевые артефакты, но работа включала следующие этапы:

Предпроектный анализ: Выявление стейкхолдеров, определение границ системы (System Context) и бизнес-целей.

Анализ процессов: Моделирование текущих процессов (As-Is) и проектирование будущих (To-Be).

Сбор требований: Написание User Stories и Use Cases, проработка функциональных и нефункциональных требований.

Проектирование: Разработка модели данных, диаграмм состояний и макетов экранных форм.

Структура репозитория (Что внутри)

Business_Processes_BPMN: Диаграммы бизнес-процессов (BPMN), включая процессы оплаты и управления расписанием.

Requirements: Детальные сценарии использования (Use Cases) и пользовательские истории (User Stories), проработанные по критериям INVEST.

System_Design: Техническая спецификация: модель данных, матрицы прав доступа (CRUD), диаграммы переходов состояний и описание полей для разработчиков.
