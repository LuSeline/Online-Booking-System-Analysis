# Online-Booking-System-Analysis
Portfolio: Barber Shop Booking System 


Этот проект — детальная проработка требований для платформы онлайн-записи.

В этом репозитории вы найдете:

Business Processes (BPMN): Визуализация 6 ключевых процессов (Запись, Оплата, Расписание).

System Specification: Детальное описание модели данных, валидации полей и UI-форм (папка System_Design).

Requirements: Проработанные User Stories (по критериям INVEST) и детальные Use Cases.

State Analysis: Матрицы переходов состояний для платежей и заказов.

Tools used: Excel, BPMN, Word, Draw.io.
